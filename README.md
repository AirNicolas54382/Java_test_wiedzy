## 📖 About The Project

This is a lightweight, educational project built to practice GUI creation and event handling in Java. The application presents a short questionnaire using standard Java window components. 

When the user fills out the form and clicks the "Zakończ" (Finish) button, the program captures the selected data, compares it directly against pre-coded correct answers within the logic, and prints the evaluation output directly to the system console.

### ✨ Key Features
*   **Multiple Input Types:** Demonstrates the implementation and data retrieval of various UI components, including:
    *   Text Fields (`Autor`)
    *   Checkboxes (`Nie jestem robotem`)
    *   Radio Buttons (`Co najgorsze?`)
    *   Dropdown Menus / ComboBoxes (`Co najtrudniejsze?`)
*   **Logic Validation:** Reads the state of each GUI element upon submission and runs a basic conditional check against the hardcoded answer key.
*   **Console Output:** Bypasses complex GUI result screens in favor of straightforward console logging to display the final test results.

## ⚙️ Installation & Execution

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/AirNicolas54382/Java_test_wiedzy
    ```
2.  Launch **IntelliJ IDEA**.
3.  Open the cloned project folder.
4.  Navigate to the `src` folder in the Project Explorer.
5.  Right-click the main class file and select **▶ Run**.
6.  *Note: Make sure to keep your IDE console visible at the bottom of the screen, as the test results will be printed there after interacting with the GUI.*
